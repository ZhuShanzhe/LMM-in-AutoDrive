## 4. 参数统计表

参数量于 2026-07-30 直接从提交包权重张量或实例化模型统计；不是根据模型名称估算。

| 模型 | 实测参数量 | 权重文件/目录大小 | 推理精度 | 已有延时 |
|---|---:|---:|---|---|
| Qwen3-ASR-1.7B 完整语音模型 | 2,349,217,408 | 4,703,117,479 bytes | BF16 权重 | 普通话合成指令字符准确率 96.04% |
| Qwen2.5-3B-Instruct 翻译 | 3,085,938,688 | 6,183,468,087 bytes | BF16 权重 | 离线术语约束翻译 |
| DeepFilterNet3 | 约 2.1M（模块文档） | 约 8.3 MB | FP32 | 按噪声配置启用 |
| ModernBERT 最终 Backbone + 两个任务头 | 149,051,184 | 约 302 MB | BF16 Backbone | 解析前 1,000 条 P95 12.97 ms |
| ModernBERT-base 预训练 Backbone | 149,655,232 | 精简后约 600 MB | FP32 | 不进入默认独立推理 |
| YOLOP | 7,940,846 | 95,756,827 bytes 主权重 | FP32 检查点 | 与组合感知统一统计 |
| YOLO11s CARLA 最终模型 | 9,460,953 | 19,164,762 bytes | FP32 检查点 | CARLA 域适配 640 稳态 P95 41.36 ms |
| YOLO11s 预训练模型 | 9,488,817 | 19,313,732 bytes | FP32 检查点 | 仅训练初始化 |
| 轻量 VLA v10 | 4,170,254 | 16,702,367 bytes | FP16 实测路线 | 文本到 proposal 特征 P95 17.30 ms |

场景二 127 条抽样日志中，帧流水线 P50/P95 为 29.360/35.188 ms，感知为
24.467/29.159 ms，VLA 模型为 3.292/3.935 ms，VLA/FSM 决策为
3.951/4.559 ms。该口径从预计算指令 token 后开始，不包含 ASR 和翻译。

FLOPs、功耗和车规芯片实机峰值属于挑战赛道部署报告，不使用估算值填充。本表目录
大小包含配置、分词器和模型卡时会略大于单个权重文件。

- 上游模型和数据许可证分别生效，提交权重不代表获得上游再许可权；
- 最终提交包中附一份许可证索引，并确认竞赛评审和后续展示用途被允许。
