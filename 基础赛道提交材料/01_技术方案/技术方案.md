# 面向智能驾驶的大模型语音控制系统技术方案

## 1. 项目概述

本项目面向 XH-202602 基础赛道，构建从中文驾驶语音到 CARLA 车辆响应的模块化多模态系统。系统处理语音、相机、LiDAR、车辆状态和环境状态，输出受约束的高层驾驶决策，再由状态机、规则规划器和 PID 控制器执行。

设计目标是同时满足自然语言组合表达、视觉实体落地、实时决策和安全可解释性。大模型或学习模型不直接输出油门、制动和转向量；所有动作需经过结构校验、语义对齐、风险门控和有限状态机。

## 2. 需求与指标

系统覆盖：

- 基础操控：启动、停止、加减速、定速、转向、变道；
- 复杂避障：行人、慢车、公交站、锥桶等目标条件下的组合动作；
- 极限应急：雨天、夜间、施工、加塞等场景下的模糊或紧急指令；
- 方言、轻微噪声、同义改写、多动作、条件、否定修正、相对描述和指代。

基础赛道核心指标以题目原文为准：识别准确率不低于 95%，指令解析延时不高于 50 ms，端到端决策响应延时不高于 150 ms，场景任务完成率不低于 90%，多模态语义对齐精度不低于 98%。极限应急场景响应延时不高于 120 ms。

## 3. 总体架构

```text
中文语音
  -> 降噪 / ASR
  -> 中文文本与置信信息
  -> 术语映射和可选翻译
  -> ModernBERT + 规则短路
  -> DrivingIntent 1.2
  -> 相机 / LiDAR / CARLA Actor 与 Map / 自车状态
  -> PerceptionFrame + WorldState
  -> 目标实体对齐 + 风险评估
  -> 原规则决策或轻量 VLA proposal
  -> 确定性安全门 + ControlPlan FSM
  -> ControlDecision 1.0
  -> CARLA 协议 + PID
  -> 车辆轨迹、事件、指标和视频
```

系统保留两条动作生成链路：

1. 原规则链路根据结构化意图、场景语义和风险生成 canonical decision，稳定且可作为安全兜底；
2. 轻量 VLA 使用相机/LiDAR BEV、候选实体、自车状态和 ModernBERT 意图 token 生成场景条件化 proposal。

两条链路共享风险门、FSM 和 CARLA 控制协议。VLA 输入不完整、置信度不足、动作与语言冲突或安全条件不满足时，自动回退 canonical decision。

## 4. 四大模块

### 4.1 语音解析

`automatic_speech_recognition/` 提供录音、降噪、FunASR/Qwen3-ASR 和测试入口；`structured_command_parser/` 将文本规范化、原子动作分解并输出 `DrivingIntent 1.2`。显式速度、方向、顺序、条件、否定和实体引用采用确定性槽位保护，ModernBERT 负责动作与语义 token 预测。

### 4.2 视觉理解

`scene_understanding/` 组合 YOLOP、YOLO11s、跟踪、道路结构、CARLA 真值投影和可选异步 VLM。实时安全链路优先结构化感知；异步 VLM 用于低频场景解释，不阻塞紧急制动。

### 4.3 语义对齐

语言实体只能在候选实体集合中匹配，不允许模型自由生成目标。对齐结合类别、颜色/属性、相对位置、车道关系、距离、TTC 和可见性；歧义、未知指代、路线能力不足或过期感知返回拒绝或澄清。

### 4.4 动作生成

原规则链路和轻量 VLA 均输出离散高层动作与目标速度/实体。确定性风险门处理碰撞风险、目标车道安全、交通灯和应急覆盖，FSM 管理多步骤顺序、触发、完成条件和阻塞策略，最后转换为 CARLA 控制量。

## 5. 安全与容错

- `EMERGENCY_BRAKE` 和高风险减速具有最高优先级；
- 目标实体未唯一解析时不执行依赖目标的动作；
- 目标车道不安全时拒绝变道；
- 显式速度在 `DrivingIntent.parameters.target_speed_mps` 中保留，下游统一转换为 km/h；
- VLA proposal 不能改变明确方向、绕过风险门或直接控制执行器；
- 时序监督抑制单帧动作和目标抖动，高风险事件同帧响应；
- 模型缺失、输入缺失、推理异常或低置信度时回退规则链路；
- 日志记录原指令、解析结果、场景状态、决策、控制、延时和异常原因。

## 6. 数据与训练

语言部分使用 Talk2Car、SimLingo 和组合泛化增强数据；视觉部分使用 BDD100K、nuScenes 和 CARLA 域数据；VLA 学生模型使用 SimLingo 张量数据、代理样本和 CARLA 捕获数据。所有划分按源样本/场景分组，避免同源样本跨集合泄漏。

详细来源、规模、标注和限制见 `04_数据集构建/数据集构建与验证报告.md`。

## 7. 已完成验证摘要

- Qwen3-ASR 在 8,349 条普通话合成指令上的字符准确率为 96.04%；句子准确率为 48.58%，两者不可混用；
- ModernBERT 在 66,270 条伪标签测试集上的动作 exact match 为 98.70%，属于教师一致率，不是人工金标准准确率；
- ModernBERT 前 1,000 条端到端解析 P95 为 12.97 ms；分层长尾 50 条 P95 为 19.01 ms；
- 场景理解现有三类 CARLA 小规模验证为 3/3，无碰撞和违规，但样本不足以形成正式统计；
- 轻量 VLA v10 在 82,262 条广义官方 validation 上原始动作准确率 84.18%，安全门后 canonical 动作准确率 94.66%；
- 轻量 VLA 文本到 proposal 特征 P95 为 17.30 ms，不包含 ASR、原始传感器编码、规划和控制；
- 时序监督将 230 帧压力序列的动作切换从 83 次降到 4 次，危险帧错误加速从 51 次降到 0。

以上为不同测试范围的阶段结果，不能相加或直接替代正式三场景全链路验收。
