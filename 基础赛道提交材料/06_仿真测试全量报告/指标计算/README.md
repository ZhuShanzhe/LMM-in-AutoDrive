# 指标计算与原始字段

正式评测脚本和原始汇总尚未归档到本目录。提交前应固定以下口径。

## 场景任务完成率

```text
任务完成率 = 同时完成场景目标、无碰撞、满足违规限制且无指令遗漏的运行次数 / 全部有效启动的运行次数
```

超时、决策失效、控制进程异常和模型崩溃均计失败；基础设施故障应单独标记，但不得无记录删除。

## 语音指令识别

同时报告 CER、WER、句子完全匹配率和驾驶关键槽位正确率。用于比赛计分的“识别准确率”必须在报告中给出唯一公式，不能在不同场景切换口径。

## 指令解析

报告动作 exact match、步骤完全匹配、目标/条件/关系 F1、状态准确率和延时。人工金标准与伪标签教师一致率分开。

## 多模态语义对齐

```text
对齐精度 = 正确落地到目标实体/道路元素/触发条件的决策相关引用数 / 全部可判定引用数
```

歧义时正确拒绝应单列，不能以 CARLA 真值自匹配替代模型对齐结果。

## 延时

- ASR；
- 翻译/规范化；
- 结构化解析；
- 传感器编码和感知；
- 语义对齐与风险；
- VLA/规则决策；
- FSM/控制协议；
- 语音结束到首个有效控制决策的端到端响应。

统一使用单调时钟，报告样本数、预热、硬件、P50/P95/P99 和最大值。

## 安全事件

记录碰撞、非法压线、闯灯、超速、安全距离、最小 TTC、紧急制动反应时间、指令遗漏和非预期动作。每项可追溯到运行 ID、仿真帧和视频时间。
