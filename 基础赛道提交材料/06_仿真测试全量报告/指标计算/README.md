## 任务完成

```text
单次任务完成 = 路线达到终点 AND 最终计划完成 AND 碰撞为 0 AND 非法违规为 0
```

当前每个场景只有一条正式归档运行，因此报告单次运行结果，不以 `2/2=100%` 冒充多种子统计。

## 延时

- 使用日志中的单调仿真时间和模块计时；
- P50 为中位数；
- P95 为排序后 95% 位置；
- 场景一 `response_latency_ms` 是指令调度到控制决策；
- 场景二 `frame_pipeline_ms` 从当前传感器帧处理开始，不包含预计算 ASR、翻译和 ModernBERT token。

## 安全事件

- 碰撞：CARLA CollisionSensor 事件数；
- 车道侵入：LaneInvasionSensor 原始事件；
- 非法车道侵入：结合路线指令、地图车道和允许变道状态后的违规事件；
- 相机同步跳帧：未在时限内获得对应帧，单独记录但不删除运行。

## 语音和语义指标边界

ASR、指令解析、语义对齐的离线准确率见各模块 README。当前两场景日志不包含人工金标准逐条评分，因此不从 CARLA 真值自匹配推导新的“多模态对齐精度”。
