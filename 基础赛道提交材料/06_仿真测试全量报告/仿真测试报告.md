# CARLA 两场景仿真测试报告

## 1. 当前范围

本审核版归档场景一基础语音操控 5 km 和场景二多模态闭环 8 km。场景三暂缓，相关代码和设计配置保留，但不纳入本报告结果或完成率。

## 2. 测试环境

| 项目 | 配置 |
|---|---|
| CARLA | 0.9.16，Linux headless/off-screen |
| Python | 3.12.13 |
| PyTorch / CUDA | 2.11.0+cu130 / CUDA 13.0 |
| GPU | NVIDIA GeForce RTX 5090，32 GB，SM120 |
| CPU | Intel Xeon Platinum 8470Q |
| 内存 | 754 GiB |
| 控制链路 | DrivingIntent -> 场景理解/VLA -> 安全门/FSM -> PID |

模型文件位于提交包根目录 `models/`，环境与依赖入口见根目录 `submission_env.sh` 和各模块 README。

## 3. 场景一：基础语音操控

场景一使用城市道路、连续 5 km 路线、动态交通流和 15 条基础驾驶指令，覆盖车道保持、目标速度切换、左右变道和路口转向。

| 指标 | 结果 |
|---|---:|
| 行驶距离 | 5,031.581 m |
| 仿真时长 | 524.25 s |
| 指令数 | 15 |
| 平均 / 最高车速 | 34.551 / 59.565 km/h |
| 碰撞 | 0 |
| 非法车道侵入 | 0 |
| 超速帧 | 0 |
| 响应延时均值 / P95 | 7.647 / 8.934 ms |
| 控制延时均值 / P95 | 0.155 / 0.240 ms |
| 任务状态 | SUCCESS |

原始佐证：

- `原始时序数据/scene_1_basic/metrics.json`
- `原始时序数据/scene_1_basic/metrics.csv`
- `原始时序数据/scene_1_basic/events.jsonl`
- `原始时序数据/scene_1_basic/telemetry_sampled.jsonl`

记录中共有 12 次车道线传感器事件，但根据路线指令和地图语义判定，非法车道侵入为 0；两者在报告中分别保留。

8 km 多模态闭环与安全控制验证，不将该次运行描述为完整复杂避障任务验收。
