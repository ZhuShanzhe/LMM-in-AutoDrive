## 4. 已完成工程验证

### 4.1 CARLA 三类小规模验证

现有场景理解报告记录：

| 场景 | 结果 | 条件 |
|---|---|---|
| 直线行驶 | 成功 | 到达目标且保持车道 |
| 行人横穿 | 成功 | 行人通过并清空冲突区 |
| 紧急制动 | 成功 | 前车急停后保持安全间距停车 |

汇总为 3/3、碰撞率 0、违规率 0。该结果是工程冒烟和接口验收，样本规模为 3，不足以作为正式 90% 场景任务完成率统计。

紧急制动安全修复后另执行严格场景 3 次，均为 `safe_stop_after_front_brake`：触发速度 19.384-19.400 km/h，反应时间 0.200 s，最终速度 0 km/h，最小前车距离 11.661-11.938 m，碰撞、非法压线和超速误报均为 0。

### 4.2 ASR

| 测试 | 样本 | 指标 |
|---|---:|---|
| Qwen3-ASR 普通话合成指令 | 8,349 | 字符准确率 96.04%，词准确率 89.45%，句子准确率 48.58% |
| 噪声子集 | 500 | 无噪句准确率 46.0%，加噪后 36.4% |
| DeepFilterNet3 对照 | 1,000 | ASR CER 0.0390；降噪后 CER 0.0179 |

赛事“语音指令识别准确率”最终采用何种匹配口径需要在统一评测脚本中固定。字符准确率不能与句子完全准确率混用。

### 4.3 结构化指令解析

| 范围 | 结果 |
|---|---|
| ModernBERT 66,270 条伪标签测试 | 动作 exact match 98.70%，micro-F1 97.78% |
| 端到端解析前 1,000 条 | 动作 exact match 99.30%，P95 12.97 ms |
| 分层长尾 50 条 | 动作 exact match 70.00%，micro-F1 88.32%，P95 19.01 ms |
| 175 条开发挑战集回归 | 修复后图/动作/关系/实体 100%，P95 约 87 ms |

66,270 条为教师一致率；175 条开发集参与过规则修复。两者均不能替代独立人工金标准。

### 4.4 场景理解

默认 YOLOP 640 + CARLA 域适配 YOLO11s 640。CARLA 灯头域适配 640 的召回/精度/F1 为 17.67%/56.43%/26.91%，稳态 P95 41.36 ms。多模态语义对齐 98% 尚无独立决策相关对象金标准结果。

### 4.5 轻量 VLA

| 数据 | 样本 | 原始动作准确率 | 安全门后 canonical 准确率 |
|---|---:|---:|---:|
| 固定官方 validation | 24,361 | 79.90% | 91.77% |
| 广义官方 validation | 82,262 | 84.18% | 94.66% |
| CARLA 三类域测试 | 908 | 98.68% | 100.00% |

安全门后指标包含确定性 fallback，不是学生模型独立准确率。CARLA 域测试只覆盖 `keep_lane`、`decelerate`、`emergency_brake`。

文本到 proposal 特征 P95 为 17.30 ms；不包含 ASR、翻译、原始传感器编码、规划器和控制器。

## 5. 指标计算

统一公式和原始字段见 `指标计算/README.md`。正式统计必须以完整场景运行作为分母，并同时满足任务目标、碰撞、违规和指令遗漏条件。

## 6. 正式测试矩阵

每个场景至少按以下维度形成可重复矩阵：

- 场景 1：路线、出生点、指令顺序、目标速度和随机种子；
- 场景 2：交通密度、行人、公交、非机动车、光照和组合指令；
- 场景 3：雨量、夜间亮度、施工布局、加塞时机、行人时机和语音噪声；
- 每次保存配置、种子、权重 SHA256、全量时序日志和视频；
- 成功与失败均纳入分母，不删除异常运行。
