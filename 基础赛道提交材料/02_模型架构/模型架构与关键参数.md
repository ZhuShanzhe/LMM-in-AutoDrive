# 模型架构与关键参数

## 1. 四模块数据流

| 模块 | 输入 | 核心实现 | 输出 |
|---|---|---|---|
| 语音解析 | 中文语音/文本、ASR 置信信息 | DeepFilterNet3、FunASR/Qwen3-ASR、ModernBERT、规则校验 | 文本、`DrivingIntent 1.2` |
| 视觉理解 | 前视/多视角图像、LiDAR、CARLA 状态 | YOLOP、YOLO11s、跟踪、道路结构、可选 VLM | `PerceptionFrame`、`WorldState` |
| 语义对齐 | DrivingIntent、候选实体、道路和自车状态 | 约束实体检索、关系匹配、TTC 和风险规则 | 对齐结果、`RiskAssessment` |
| 动作生成 | 意图、场景特征、风险、计划状态 | 规则决策或 4 层 Cross-Attention VLA、安全门、FSM | `ControlDecision 1.0` |

接口 Schema 位于 `structured_command_parser/schemas/`、`scene_understanding/schemas/` 和 `lightweight_vla_adapter/schemas/`。

## 2. 语音与指令解析

### 2.1 ASR

- 默认高精度路线：Qwen3-ASR-1.7B；
- 轻量路线：FunASR；
- 噪声预处理：DeepFilterNet3，文档记录约 210 万参数和约 8.3 MB FP32 权重；
- 输入采样率和设备参数以 `automatic_speech_recognition/src/` 配置为准。

### 2.2 ModernBERT 结构化解析

- Backbone：ModernBERT；
- 主任务：动作、类别、紧急度、方向、速度变化等多任务分类；
- 辅助任务：实体/关系 token 头；
- 规则短路：显式数值、危险/非法边界、否定修正和常见确定性表达；
- 训练切分：463,890/132,540/66,270，另加入 108 条稀有动作定向样本；
- 语义 token 头：3,288/1,065 训练/验证样本，8 epoch；
- 输出：`DrivingIntent 1.2`，速度统一为 `target_speed_mps`。

模型完整配置、标签和阈值以权重目录与 `structured_command_parser/configs/` 为准。

## 3. 视觉理解与语义对齐

- 道路结构：YOLOP；
- 交通对象：YOLO11s 专项权重；
- 跟踪：实时跟踪器维护实体 ID；
- CARLA：Actor/Map/TrafficLight API 提供仿真安全真值与投影；
- 异步语义：Qwen2.5-VL-3B 或 MiniCPM-V 只用于低频解释和离线对照；
- 默认实时图像：640×360，YOLO11s object image size 640；
- 默认检测阈值：0.10；
- 高精度可选：object image size 768，但延时余量较小；
- 对齐：类别、属性、相对位置、车道、距离、可见性、TTC 和指令关系共同约束。

## 4. 轻量 VLA Decision Adapter

### 4.1 输入

- camera BEV：8 通道；
- LiDAR BEV：4 通道；
- 候选实体特征：每个实体 12 维；
- 自车状态；
- ModernBERT 768 维意图 token。

当前结构化 BEV 可以从官方三维标注、CARLA 真值或结构代理生成。真实原始多视角图像和点云到训练同分布 BEV 的统一编码器仍需在最终全链路中固化。

### 4.2 网络

- 轻量相机 BEV 编码器；
- 轻量 LiDAR BEV 编码器；
- 4 层 Cross-Attention Decision Adapter；
- 动作、目标实体、目标速度和置信度输出头；
- `TemporalProposalSupervisor`；
- 确定性安全门和 canonical fallback。

配置文件：`lightweight_vla_adapter/configs/student_base.json`。

### 4.3 输出和边界

VLA 输出 `VLADecisionProposal 1.0`，不直接输出轨迹或执行器控制量。经过安全门和 FSM 后转换为 `ControlDecision 1.0`。风险门、目标车道安全和紧急制动不能被学习模型覆盖。

## 5. 调参记录摘要

| 模块 | 已记录调参 | 选定配置/结论 |
|---|---|---|
| ASR | FunASR/Qwen3-ASR、噪声前后、DeepFilterNet3、方言分层 | Qwen3-ASR 精度优先；噪声场景启用降噪 |
| ModernBERT | 两阶段训练、阈值校准、规则/BGE/Qwen 对照 | ModernBERT + 确定性规则为默认实时路线 |
| 场景理解 | 640/768、阈值 0.10/0.05/0.025、双分块 | 默认 640、阈值 0.10；双分块只离线 |
| VLA | 代理数据、SimLingo、CARLA 域校准、安全门和时序监督 | v10 + safety gate + temporal supervisor |
| CARLA 控制 | 固定航向/waypoint、紧急锁存、超速/压线口径 | waypoint 车道保持、风险分级和严格事件统计 |

参数量由提交权重张量或实际实例化模型统计，完整文件大小和许可证见
