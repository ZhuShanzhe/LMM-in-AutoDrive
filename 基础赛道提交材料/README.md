## 系统模块

| 题目模块 | 代码目录 | 稳定输出 |
|---|---|---|
| 语音解析 | `automatic_speech_recognition/`、`structured_command_parser/` | ASR 文本、`DrivingIntent 1.2` |
| 视觉理解 | `scene_understanding/` | `PerceptionFrame`、`WorldState`、候选实体 |
| 语义对齐 | `scene_understanding/` | `SemanticAlignment`、`RiskAssessment` |
| 动作生成 | `lightweight_vla_adapter/` 或原规则链路 | `VLADecisionProposal 1.0`、`ControlDecision 1.0` |
| 仿真执行与评测 | `experiment/CARLA/` | CARLA 控制、事件日志、指标和视频 |

## 当前统一环境

```text
Ubuntu 22.04 / Linux
Python 3.12.13
CARLA 0.9.16
NVIDIA Driver 580.105.08
CUDA 13.0
RTX 5090 / sm_120
```

各模块依赖不同，按模块 README 分环境安装，不在根目录一次性安装全部依赖。

## 提交前规则

1. 所有结果必须能追溯到原始日志、样本清单和运行配置。
2. 教师一致率、开发集回归率和小规模冒烟成功率不得写成正式独立测试准确率。
3. 权重、数据集、视频和全量日志不适合进入 Git，但最终邮件压缩包必须按赛事要求一并提供，或提供评委可访问且许可证允许的下载方式。
4. 删除令牌、密码、AutoDL 登录信息、个人缓存、绝对临时路径和 `.git/`。
5. 压缩前逐项完成 [提交清单](00_提交管理/提交清单.md)。
