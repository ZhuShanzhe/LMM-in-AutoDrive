# 多模态融合与场景适配

## 1. 输入对齐

系统按 `request_id`、仿真帧号和时间戳关联语音、图像、LiDAR、车辆状态和环境状态。语音指令在计划生命周期内持续有效；传感器帧按时间新鲜度参与决策，过期感知不能触发目标相关动作。

统一数据对象：

- `DrivingIntent 1.2`：动作、参数、目标、条件、顺序、约束和解析状态；
- `PerceptionFrame`：同帧检测、车道和传感器元数据；
- `WorldState`：候选实体、交通设施、自车和道路关系；
- `RiskAssessment`：TTC、碰撞风险、车道安全和建议动作；
- `VLADecisionProposal 1.0`：学习模型的高层建议；
- `ControlDecision 1.0`：安全门和 FSM 后的唯一执行决策。

## 2. 融合方法

### 2.1 显式语义对齐

指令中的目标引用被转换为实体查询，在场景候选集合内检索。匹配考虑类别、属性、相对方位、车道、深度、可见性和时序关系。候选不唯一时返回歧义，不允许语言模型自由生成不存在的对象。

### 2.2 特征级融合

轻量 VLA 同时编码 camera BEV、LiDAR BEV、候选实体、自车状态和 ModernBERT 意图 token，通过 4 层 Cross-Attention 输出高层动作、目标和速度。该 proposal 作为名义建议，不替代风险评估和执行状态机。

### 2.3 决策级融合

系统维护 canonical rule decision 和 VLA proposal。安全门根据指令一致性、目标唯一性、目标车道安全、碰撞风险、TTC、置信度和输入完整性选择：

- 接受 VLA；
- 用风险约束修正 VLA；
- 回退 canonical rule decision；
- 拒绝并请求澄清；
- 紧急制动或安全停车。

当前“动态权重”主要通过风险和置信度驱动的离散门控实现，不声称已完成连续可学习权重的独立消融。

## 3. 鲁棒性策略

### 3.1 噪声与方言

- DeepFilterNet3 降噪；
- Qwen3-ASR 方言识别；
- ASR 疑义保留到解析结果；
- 同音修正无法可靠确定时返回 `NEEDS_CLARIFICATION`。

### 3.2 模糊与长尾语言

采用“规范化、原子分解、实体检索、规则验证”：

- 同义改写映射到受约束动作集合；
- 多动作保留依赖和 `BEFORE/AFTER/UNTIL` 关系；
- 否定和修正覆盖被否定动作；
- 相对描述保留序数和路线要求；
- 省略指代没有先行实体时不猜测；
- 明确目标速度从源语言恢复，避免翻译丢值。

### 3.3 视觉与传感器异常

- 安全同步链路不等待异步 VLM；
- CARLA Actor/Map/TrafficLight API 用作仿真安全真值；
- 相机与 LiDAR 缺失时降低 proposal 可信度并回退；
- 小目标检测采用 640 默认配置，768 只在有延时余量时启用；
- 帧时间戳过期、实体消失或 ID 切换触发重新对齐。

### 3.4 决策稳定性

`TemporalProposalSupervisor` 使用动作切换滞回、目标锁定和风险覆盖抑制逐帧抖动。正常状态需要连续证据才切换动作；高风险事件同帧覆盖，不等待滞回窗口。

## 4. 分场景逻辑

### 4.1 基础操控

清晰天气和道路条件下执行车道保持、定速、转向和变道。速度使用明确单位，转向和变道需满足地图拓扑和目标车道安全。

### 4.2 复杂避障

组合指令拆为减速/避让/变道/恢复等步骤。目标实体与视觉候选对齐，风险门决定何时减速或等待，FSM 确认前一步完成后推进下一步。

### 4.3 极限应急

雨夜、施工和突发交通参与者场景提高风险优先级。紧急制动、减速和安全停车覆盖普通加速建议；感知置信度不足时使用保守策略。

场景三在当前审核版暂缓，以上为已实现的设计与代码能力，不作为本版实测结果。

## 5. 当前两场景验证

- 定向实体唯一/歧义、路线能力不足、ASR 疑义和未知指代测试已通过；
- 230 帧 VLA 时序压力测试将动作切换从 83 次降到 4 次，危险帧错误加速为 0；
- 场景一完成 5 km 基础语音控制闭环，15 条指令全部发出，碰撞和非法车道侵入为 0；
- 场景二完成 8 km 感知、VLA、FSM 和控制闭环，8 条指令、36 辆交通车，碰撞和车道侵入为 0；
- 场景二 127 条抽样记录的帧流水线 P50/P95 为 29.360/35.188 ms，感知 P50/P95 为 24.467/29.159 ms，语义对齐 P50/P95 为 0.241/0.482 ms。

当前场景二日志对应安全闭环指令版本，主要证明多模态链路可持续运行；完整复杂障碍事件配置虽已提供，但不将本次结果表述为完整复杂避障验收。独立人工金标准对齐精度、多种子矩阵和场景三留待后续正式评测。
