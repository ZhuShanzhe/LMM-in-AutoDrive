## 2. 语言预处理与标注

### 2.1 处理流程

```text
原始英文驾驶指令
  -> 清洗去重
  -> 术语和动作盘点
  -> 伪标签生成
  -> Schema 校验
  -> 组合/反事实增强
  -> 按源场景分组切分
  -> ModernBERT 训练、校准和测试
```

英语知识盘点覆盖 662,700 条去重记录。ModernBERT 基础切分为 463,890/132,540/66,270，另有 108 条稀有动作定向样本。该大测试集衡量模型与伪标签教师的一致率，不等同于人工金标准准确率。

### 2.2 标注规范

语言输出遵循 `DrivingIntent 1.2`：

- 动作节点；
- 目标/场景实体节点；
- 条件和触发节点；
- 时序和指代关系；
- 速度、方向、距离等参数；
- 安全、交通规则和驾驶风格约束；
- `VALID`、`NEEDS_CLARIFICATION`、`UNSUPPORTED` 等解析状态。

Schema 位于 `structured_command_parser/schemas/driving_intent.schema.json`，完整字段说明见 `structured_command_parser/DRIVING_INTENT_REFERENCE.md`。

### 2.3 数据增强

- 同义改写；
- 动作、方向、目标、条件、顺序和约束的组合；
- 最小反事实对；
- 否定和修正；
- 指代与省略；
- 数值和单位变体；
- ASR 同音和轻微文本噪声；
- 稀有动作定向补样。

## 3. 视觉和多模态预处理

- BDD100K：生成检测清单和专项 YOLO 数据；
- nuScenes：解析相机、LiDAR、标定和三维标注，生成统一样本；
- CARLA：同帧保存 RGB、Actor 投影、WorldState 和场景索引；
- SimLingo：审计分片后转换为固定张量 shard；
- VLA：生成 camera BEV、LiDAR BEV、候选实体、自车和意图特征；
- 所有样本通过 Schema、维度、时间戳、实体 ID 和标签范围校验。

当前 camera/LiDAR BEV 的训练数据主要来自官方三维标注、CARLA 真值或结构代理。运行时接口定义、结构化输入示例和安全回退均随代码提交；当前材料不把结构代理结果表述为完整原始传感器端到端训练。

## 4. 数据划分和防泄漏

- 语言数据按原始样本/场景标识分组，不让同源改写跨训练、验证和测试集合；
- 视觉测试清单排除训练/验证清单；
- CARLA 按路线、天气、出生点和随机种子划分；
- 组合泛化测试应按未见表达和未见动作组合划分，而不是随机句子切分；
- 每次生成保留随机种子、输入清单哈希、配置和统计摘要。

## 5. 已有质量验证

- 语言配置和示例接受 Schema 回归测试；
- ModernBERT 测试结果附带教师一致率边界；
- BDD100K 与 nuScenes 各有 1,000 帧独立清单；
- CARLA 域适配使用隔离 straight 36 帧、447 个可见交通灯组件；
- SimLingo 下载与 shard 有独立审计脚本；
- 场景候选实体和语义对齐有结构校验及歧义拒绝测试。
- 场景一 5 km 保存完整汇总、事件和抽样遥测；
- 场景二 8 km 保存命令、事件、运行汇总及 127 条多模态流水线抽样记录；
- 提交代码的 455 项回归测试与 177 个子测试通过。

## 6. 许可证和隐私

提交前为每个数据集归档官方许可证、下载日期、版本、用途限制和再分发条件。MagicData 方言数据文档标注为 CC BY-NC-ND 4.0；SimLingo/VLA 权重存在非商业研究限制。若许可证禁止再分发原始数据，提交包只提供获取脚本、清单哈希和必要的可公开样例。

数据不得包含未脱敏个人信息、访问令牌或私有服务器凭据。

## 7. 提交随附内容和边界

- 公开结构样例位于 `样本示例/README.md` 指定的 Schema、输入和输出文件；
- 场景一、二日志位于 `06_仿真测试全量报告/原始时序数据/`；
- 模型、配置和许可证由 `models/SHA256SUMS` 校验；
- 受许可证限制的原始 Talk2Car、SimLingo、nuScenes、BDD100K 和方言音频不重复分发，提交获取与处理脚本、统计和可公开结构示例；
- 大测试集上的 98.70% 是伪标签教师一致率，不表述为独立人工金标准准确率；
- 当前两场景审核版不包含场景三、多种子闭环矩阵或独立人工金标准对齐评测。
