# 组合指令入口修复

本次修改位于 challenge-track，未训练或替换权重。

## 原因与修改

原 GenericInstructionFSM 的关键词规则会先识别一个动作，导致带“然后、再次、then”等顺序标记的文本绕过完整解析。原预期失败用例只检查 semantic_goal，不能证明实际多步骤执行。

现在组合指令优先调用完整解析服务，保留步骤及依赖；步骤不足、缺方向、重复ID、前向依赖或解析需澄清时，不暴露部分计划。显式顺序词的数量用于保守检查丢步，不声称覆盖所有自然语言组合。

新增最终执行状态检查：需澄清的指令不能被序列控制或加速建议覆盖，输出停车并记录原因。已有显式 DrivingIntent 仍由现有计划执行器处理。

## 输入与语言边界

ModernBERT 当前为英文解析服务。英文指令可直接放在 text；中文来源可同时提供 parser_text_en，前者保留原文，后者用于解析。缓存绑定原文和翻译，翻译变化不会复用原计划。

```json
{
  "text": "先右转，然后直行通过路口，再次右转。",
  "parser_text_en": "Turn right, then go straight through the junction, then turn right."
}
```

没有翻译且无法可靠解析的中文组合指令会要求澄清，不默认执行第一个关键词动作。本修复没有新增中文翻译模型，也没有宣称英文权重已支持任意中文。

## 验证

全量接口回归：1633项通过、207项子测试通过，40.85秒，无预期失败。

- 原预期失败已替换为无解析器时必须澄清、不得下发部分计划的正常测试。
- 新增顺序保留、缓存、翻译来源、缺失步骤、重复ID、方向、依赖和最终停车保护测试。
- 解析输出接入真实 DrivingPlanRuntime，以观测速度达标后才进入停车步骤；该联调使用测试解析器和模拟观测，不是CARLA物理闭环。
- 冻结真实ModernBERT权重CPU冒烟：英文三步转弯/直行及调速后停车可以保留多步骤；直传中文与模糊中文要求澄清；中文原文配英文翻译可解析为右转、直行、右转。
- 原始回归及权重冒烟记录在服务器数据盘 review_logs/20260930/compound_plan_final.log 和 compound_real_model_final.json。

真实道路三步转弯的持续观测、实体对齐和物理执行仍需完整仿真验证；本记录不将接口回归等同于三场景通过。
