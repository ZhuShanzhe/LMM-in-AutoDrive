# DriveLM Research


本目录用于记录 DriveLM（Drive Language Model）自动驾驶大模型相关调研内容。


## 内容说明


### DriveLM-CARLA_Research.md


主要内容包括：

- DriveLM 模型背景介绍；
- 自动驾驶视觉语言模型研究；
- DriveLM 数据格式分析；
- LLaMA Adapter V2 模型结构；
- DriveLM 与 CARLA 仿真环境结合分析；
- DriveLM baseline 复现实验方案；
- 对智能驾驶大模型应用的思考。

本调研面向：

- 视觉语言模型（Vision Language Model）；
- 智能驾驶语义理解；
- LLM辅助驾驶决策。
