## 3. Senna 介绍

传统端到端自动驾驶（VAD/UniAD 等）、纯驾驶 VLM 方案分别存在短板：
1. 纯端到端模型：缺少通用常识，复杂 / 稀有场景易出错，规划无可解释依据；
2. 现有 VLM 融合方案（DriveVLM）：强制大模型输出数值轨迹，大模型不擅长精准数值回归，精度受限；
3. 通用 LVLM（LLaVA/QwenVL）：未针对 6 路环视多图优化，图像 Token 爆炸、无驾驶空间感知能力。

Senna 提出分层结构化规划范式，彻底拆分两类模型分工：
1. Senna-VLM（多模态大模型）：输入 6 路环视图像 + 导航文本，输出标准化自然语言元动作高层决策（横向：直行 / 左转 / 右转；纵向：加速 / 保持 / 减速 / 停止），利用大模型常识做场景推理；
2. Senna-E2E（基于 VADv2 改造的端到端模型）：接收多视图图像、导航、VLM 输出的元动作嵌入特征，精准输出未来 3 秒车辆行驶轨迹；
3. 整体规避 LVLM 数值预测短板，同时为端到端规划引入语义先验，提升安全性与泛化性。

## 4. Senna 与同类模型对比

| **模型**  | **核心表示方式**  |  **核心特点** |
|:-:|:-:|:-:|
| VADv2  |  向量化 BEV 场景特征 | 纯端到端，无语言语义，仅数值轨迹输出  |
|  DriveVLM | VLM 输出低频轨迹点  |  大模型做数值预测，精度上限低 |
|  LLaVA/QwenVL |  单图通用多模态 Token |  无环视优化，无驾驶专属训练数据 |
| Senna  |  VLM 语言元动作 + VADv2 向量化规划 |  解耦语义决策与轨迹回归，兼顾常识与精度 |

## 5. Senna 输入输出完整流程

### 5.1 输入数据

+ 感知输入：6 路环视摄像头多帧图像（前 / 前左 / 前右 / 后左 / 后右 / 后）；
+ 文本输入：导航指令、用户驾驶提示词；
+ 辅助输入：车辆自车状态、地图矢量信息（送入 Senna-E2E）。

### 5.2 双模块输出

+ Senna-VLM 输出：标准化自然语言元动作 + 场景描述 + 规划理由；
+ Senna-E2E 输出：未来 1s/2s/3s 高精度车辆行驶轨迹坐标序列。

## 6. Senna 核心模块拆解

### 6.1 Senna-VLM 多模态驾驶大模型

+ 核心组件：视觉编码器（CLIP ViT-L/14）、驾驶视觉适配器、文本编码器、Vicuna-7b LLM、元动作编码器
  + 驾驶视觉适配器：单图原始 576 Token 压缩至 128/64/32，大幅降低多图推理显存占用，防止模型崩溃；
  + 环视专属 Prompt：<FRONT VIEW>等视角标记，区分六路图像，构建 3D 空间感知；
  + 元动作编码器：将 LLM 输出的文字决策映射为低维嵌入特征，适配 Senna-E2E 输入；
  + 六大类自动 QA 训练数据：场景描述、信号灯识别、弱势行人 / 车辆识别、周边物体运动预测、元动作规划、规划原因解释。

### 6.2 Senna-E2E 端到端规划主干

+ 基于 VADv2 向量化框架拓展，新增元动作特征交互分支：
  + 感知模块：多图 BEV 编码，生成 Agent/Map 矢量场景表征；
  + 运动预测模块：预测周边车辆、行人未来轨迹；
  + 规划 Transformer：融合地图、动态物体、导航、VLM 元动作特征，输出多时间步轨迹。

### 6.3 三阶段分层训练策略（Senna-VLM 专属）

+ 阶段 1 混合预训练：冻结 LLM 主干，仅训练视觉适配器，融合通用图文 + 驾驶描述数据；
+ 阶段 2 驾驶微调：使用环视多图，除元动作外全部 QA 数据训练；
+ 阶段 3 规划微调：仅使用元动作 QA 专项优化高层驾驶决策；
提供全参数微调（高精度，≥24G 显存）、LoRA 微调（低显存消费卡适配）两套方案。

## 7. 官方数据集与数据格式

+ nuScenes：标准公开自动驾驶数据集（1000 场景），用于验证；
  + https://www.nuscenes.org/
+ DriveX：自研百万级驾驶数据集，用于大规模预训练提升泛化。

### 数据前置要求
+ nuScenes 原始数据、CAN 总线、地图扩展包（与 VAD 共用底层数据）；
+ 自动生成 QA 脚本依赖 LLaVA-v1.6-34b 大模型；
+ 额外产出文件：`senna_nusc_qa_train.json`、`senna_nusc_qa_val.json`（训练专用问答对）

### 数据转换命令
```shell
sh data_tools/senna_nusc_converter.sh
```
+ 脚本功能：读取 nuScenes 时序标注，调用 LLaVA 自动生成全套规划 QA 训练样本。

## 8. 官方完整运行流程
环境搭建 → 复用 VAD 底层 mmdet3d 环境 → nuScenes 完整数据准备 → CAN 总线 & 地图配置 → 自动生成 QA 数据集 → 下载 Senna-7B 预训练权重 → 三阶段训练（全参 / LoRA 二选一） → 元动作规划指标评估 → 轨迹规划精度评测 → 可视化场景 & 决策 & 轨迹输出

## 11. 整体总结
+ 本项目已完成 Senna 最小复现环境搭建与单模块推理验证，本地 RTX4060 笔记本可完成轻量化版本离线推理、可视化与小规模消融实验。
+ Senna 相比纯端到端 VAD、纯 VLM 驾驶方案具备明显综合优势，非常适合作为带语言解释的多模态自动驾驶规划标准 Baseline。
+ 完整落地系统推荐架构：
  + CARLA 仿真环境 / 真实车载传感器采集 → 6 路环视图像输入 → Senna-VLM 高层语义决策 → Senna-E2E 向量化轨迹规划 → MPC 车辆控制器输出油门 / 转向 / 刹车 → 规划结果文本解释可视化
