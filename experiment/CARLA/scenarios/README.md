# 场景代码

| 目录 | 作用 |
|---|---|
| `basic/` | 5 km 基础语音操控、城市路线和动态交通流 |
| `complex/` | Town05 复杂避障路线、混合交通和事件角色 |
| `continuous/` | 连续路线场景与距离触发事件 |
| `emergency/` | 紧急制动场景 |
| `pedestrian/` | 行人横穿场景 |
| `obstacle/` | 静态障碍和道路封控场景 |
| `validation/` | 制动、变道和交通交互子场景 |
| `base.py` | 场景生命周期、状态和公共接口 |

场景负责环境、路线、交通参与者和触发事件；车辆动作统一由控制模块执行。
