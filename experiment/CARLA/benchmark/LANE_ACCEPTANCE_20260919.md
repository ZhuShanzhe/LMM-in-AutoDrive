# 隔离左变道验收

## 范围

场景一 `c04_change_left` 的独立运行。保留原始任务阈值：进入指定目标车道、
横向误差不超过0.35米、朝向误差不超过5度，并持续2秒。
测试路线采用已有Town04_Opt记录，入口为其1300米处，局部进度从0开始。
这不是正式完整场景1300米处的严格复现。

控制器为Traffic Manager测试基线，不调用语音、解析器或VLA，也不修改已冻结的交通流实现。
仿真真值只用于本次测试基线触发与独立评测，不能将这一入口作为模型无真值输入的证明。

## 实现

- `lane_fixture.py`：沿路线核查相邻车道、同向性、变道许可、连续长度及路口排除。
- `runtime.py`：记录原始档与局部入口，启动背景车流，执行基线变道，采集判定和清理。
- `safety_events.py`：增加整段安全结果，避免任务提前成功掩盖后续安全事件。
- 测试覆盖近车阻塞、后车快速接近、相邻车道不干扰、非法入口和不足长度等情况。

官方 `force_lane_change` 本身不检查碰撞，因此调用前先进行保守间距检查，并保留阻塞车辆ID。
该检查不是完整安全规划器，只用于此固定、短距离、无其他特殊事件的测试。
参考：[CARLA Traffic Manager API](https://carla.readthedocs.io/en/latest/python_api/#carla.TrafficManager)。

## 结果

最终产物：`../outputs/benchmark/lane_left_live_20260919_v3/`。

| 项目 | 结果 |
| --- | --- |
| 源车道 / 目标车道 | 38:0:-2 / 38:0:-1 |
| 实际方向 | 左变道 |
| 时长 / 帧数 | 10秒 / 200帧 |
| 请求变道 | 首帧后1.65秒 |
| 判据完成 | 首帧后6.10秒 |
| 路线进度 | 71.22米 |
| 最高速度 | 30.30 km/h |
| 背景交通 | 96辆，结束时几何可见计数5辆 |
| 安全事件 | 4条虚线跨越回调；无记录碰撞或实线压线 |
| 子任务 / 退出码 | SUCCESS / 0 |
| 清理 | 车辆0、传感器0，恢复非同步模式 |

两次10秒、同种子、同入口运行（v2、v3）的200帧速度和路线进度数值完全一致。
帧号与绝对仿真时间不同，此结果不代表所有交通状态、长场景或跨设备确定性已证明。
最终采集与离线重评的状态、原因、证据及配置/观测哈希一致。相关回归测试105项通过。

清理路径增加了Traffic Manager显式关闭与 `lifecycle.json`，连续两次命令正常返回。
客户端仍有重复取消监听警告，未将警告隐藏；本次检查未发现遗留车辆或传感器。
