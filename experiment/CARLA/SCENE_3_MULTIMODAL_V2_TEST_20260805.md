# 场景三原始多模态 VLA 架构与闭环测试报告（2026-08-05）

## 结论

最终提交配置使用文本、同帧四视角原始 RGB、车辆动态状态和环境状态，直接产生高层驾驶动作、目标速度与目标车道。结构化 BEV 和 CARLA 候选对象真值均被禁用；安全层只保留碰撞、非法变道和物理速度边界约束。该结构满足场景三“文本指令 + 低信噪比多视角视觉 + 车辆/环境状态到车辆控制接口”的提交链路要求，音频不进入本轮测试。

## 架构闭环

1. `ModernBERT` 将中文文本指令编码为 token；
2. 四个同步 RGB 相机（前、左、右、后，`224 x 224`）由轻量图像编码器直接编码；
3. 车辆状态与天气/路面环境状态分别投影为状态 token；
4. 四层跨模态注意力适配器融合上述 token，输出动作、目标速度、目标车道、置信度和视觉风险；
5. 路径/PID 执行器把模型输出接入 CARLA 转向、油门和制动接口；
6. 安全门仅在紧迫碰撞、危险变道或物理速度越界时改写模型提案。

最终配置 `lightweight_vla_adapter/configs/scene3_multimodal_v2.json` 中：

- `require_raw_camera = true`
- `use_raw_camera = true`
- `use_candidate_entities = false`
- `use_structured_bev = false`
- `allow_legacy_checkpoint = false`

若缺少四相机同步帧，控制器会失败关闭，不能退回结构化伪视觉。关闭候选实体后，候选特征不会进入融合记忆或目标指针输出，解码提案的 `target_entity_id` 固定为空。规则层的风险状态只用于独立安全约束，不作为 VLA 的候选实体输入。

## 数据与训练

- 来源：场景三 6 km 历史完整采集；每个样本包含同帧四视角图像、文本、车辆状态、环境状态和教师动作。
- 有效样本：1280；训练 1024，验证 256（固定 `index % 5 == 0` 验证划分）。
- 训练轮数：20；最佳权重按动作准确率、视觉风险准确率和速度误差联合选择。
- 权重：`/root/autodl-tmp/models/lightweight_vla_adapter/scene3_multimodal_v2/model.pt`
- 参数量：5,250,097；文件大小：21,158,391 字节。
- SHA-256：`87c74fc80b86d23c964d8b6772cc1726ff004b8c0afdc243d68cd03704b8af12`

固定验证集结果：

| 指标 | 结果 |
|---|---:|
| 动作准确率 | 100.00% |
| 视觉风险准确率 | 98.83% |
| 目标速度 MAE | 0.261 km/h |
| 去除文本后的动作准确率 | 68.75% |
| 去除图像后的视觉风险准确率 | 1.95% |

该消融证明文本决定动作语义、图像决定视觉风险；但车辆状态和环境状态消融影响较小，原因是训练数据只有单一路线和单一雨夜环境。这是现有数据集的主要泛化短板，不能用本次单场景高准确率替代跨天气、跨路线测试。

## 已知不足与后续模型工作

1. 训练数据只覆盖一个场景配置，车辆状态和环境状态尚未获得充分可辨识监督；应增加天气、摩擦、光照、交通密度和初始速度变化。
2. 当前动作类别在验证集中没有右变道和紧急制动样本，不能据此声称这两类泛化准确率。
3. 图像对动作分类的影响仍小于文本，视觉分支主要学到风险辅助任务；后续应加入“相同文本、不同视觉危险状态、不同正确动作”的反事实样本。
4. CARLA 车道侵入传感器会在合法路口或计划变道时产生原始触线事件，因此验收以独立的 `invalid_lane_samples` 为准，同时保留原始事件数供审计。
5. 规则层当前使用 CARLA 环境风险状态做安全验证；正式部署时必须由感知模块生成同结构风险状态，不能读取仿真器对象真值。
6. 普通巡航时速度头约输出 40 km/h，高于本次湿路执行上限 30 km/h；PID 执行器已按物理上限裁剪，因此车辆安全但模型速度预测本身不合格。后续应把湿路上限写入训练标签并加入多摩擦系数反事实样本，而不是依赖执行器长期修正。
