# 跨地图交通灯观测与闭环验证

本文保留已完成的研发证据。下文采集、训练脚本和 `outputs/` 路径均指服务器 `zsz/lightweight_vla_adapter/` 工作区，不随挑战运行分支分发。当前安装、权重路径与接口以 [模块 README](README.md) 为准，不使用个人实验输出作为运行依赖。

## 本轮改动

本轮训练了独立的灯色观测小模型，修复跨路口灯具关联、红绿切换后重新识别及颜色阈值造成的拒识问题。VLA 主干、ModernBERT 和递归时序权重未重新训练或替换。灯色识别准确率不等同于 VLA 原始决策准确率。

旧版使用通用 YOLO11s 检测灯具，再用固定 HSV 阈值分类；检测器漏检后只能保留旧灯具位置，不能据此引入绿灯。原 v10 三次测试都是同一 1647 号信号，三次无红灯越线，但仅一次恢复通行。新版没有按某个信号编号编写特殊判断。

```text
道路/车道 + 自车位姿 + 已校验静态地图
                  |
          关联当前受控信号及灯头
                  |
同步前视 RGB -> 灯头投影裁剪 -> LampStateNet
                  |
       当前发光证据 + 置信度 + 冲突检查
                  |
       RED / YELLOW / GREEN / UNKNOWN
                  |
新鲜度检查 + 连续绿灯确认 -> 最终交通约束 -> 原 PID 执行
```

LampStateNet 为三组卷积、ReLU、池化及分类头，输入为 RGB 48×64 灯头裁剪，参数量 **56,148**。一次批量识别同一信号的多个灯头；可见灯头颜色冲突时输出 UNKNOWN。模型置信度阈值为 0.9，绿灯必须有当前图像中的绿色发光证据，整块纯绿色遮挡不算灯具。

位置与灯色职责分开：静态地图只提供灯头空间位置及停车线，不提供动态灯色。在线模块不调用交通灯动态状态接口；灯色来自当前图像。原有观测有效期 0.25 秒、连续确认绿灯 0.3 秒，以及未知状态的停车约束保持不变。旧通用检测器仅在未配置灯色模型的历史模式下加载。

## 第一、二轮数据与训练

| 用途 | 地图 | 信号组数 | 灯头图像数 |
|---|---|---:|---:|
| 训练 | Town04 | 13 | 656 |
| 验证和选模 | Town05 | 4 | 832 |
| 训练外地图检查 | Town01 | 12 | 640 |

共 **2,128 张**裁剪，覆盖晴天、湿阴、夕阳、夜间，停车线前 8/18/30/45 米，以及红、黄、绿、熄灭状态。不同信号可包含多个灯头，所以信号组数与图像数不成固定比例。

标注只在离线采集中使用 CARLA 灯色真值。采用同一位姿、天气下的亮灯/熄灯配对图像确认发光可见性，避免把旧 HSV 规则的错误拒识当成标签。原始标签、配对依据、投影框、信号、天气及采样帧号均保留。该数据是自动标注仿真数据，不称为人工金标准。

Town02 没有获得完整有效采集；Town05 在部分位置发生引擎退出，使用已逐批保存且亮灯/熄灯配对完整的四组信号。失败和中断日志保留，不计入模型准确率，也不宣称所有计划采集均已完成。Town01 曾用于标注质量检查，不宣称它是从未查看过的盲测集；它不参与梯度训练或权重选择。

训练包含水平翻转、亮度变化、模糊和噪声增强，进行 60 轮训练。按 Town05 的宏平均召回率选模，同召回率时以验证损失选取置信度更充分的权重，最终为第 44 轮。

## 第一、二轮离线结果

| 版本及口径 | Town05 验证 | Town01 训练外检查 |
|---|---:|---:|
| 第一轮原始分类准确率 | 100.00% | 97.97% |
| 第一轮接入置信度和旧颜色占比检查 | 88.58% | 65.78% |
| 第二轮原始分类准确率 | 100.00% | 98.59% |
| 第二轮完整观测判定准确率，含 UNKNOWN | **99.64%** | **92.03%** |
| 第二轮红灯召回率 | **100.00%** | **100.00%** |
| 第二轮绿灯召回率 | 98.56% | 85.63% |
| 红灯/黄灯/未知状态误判为绿灯 | **0** | **0** |

第一轮的问题不是只看错颜色：整块裁剪的颜色占比检查把夕阳、背景和灯壳反光混入统计，造成拒识；同准确率时过早选中的权重也存在置信度不足。第二轮使用灯头核心区域的当前发光证据，不再要求整块图像以绿色为主。

第二轮 Town01 的 51 个错误均是有灯色时拒识为 UNKNOWN，其中黄灯 28 个、绿灯 23 个；没有把它们掩盖为正确识别。未知/熄灭类为 160 张，正确分类 160 张。以上是灯头裁剪分类指标，车辆是否安全停车并恢复由独立闭环记录评价。

## 第三轮：视角、灯型与近距离修正

第二轮真实闭环在 Town04 为 6/6 通过，Town01 为 2/4 通过，十次均无碰撞或红灯越线。Town01 两次失败分别是停车后绿灯拒识，以及恢复后在停车线附近因绿灯置信度不足再次停车。原始失败报告保存在 `outputs/signal_generalization_v1/final_Town01/`，未改写为通过。

采集相机的早期配置为高位、水平视角，与实际车载前视相机不同。第三轮直接复用车载 `CAMERA_TRANSFORMS['front']` 的外参：相对位置 (1.45, 0, 1.55) 米、俯仰 -3 度，并增加停车线前 0/4 米的近距离样本。在线灯头投影改用对应图像曝光时的相机位姿；图像、位姿同步缓存和过期，不使用车辆稍后的位置投影旧图像。

同时增加外围背景替换和小幅投影平移增强。训练覆盖悬挂式灯和其他路口的路侧灯，但不使用失败测试路口的数据训练。依据 CARLA 静态信号组，将 Town01 的 360–371 整组信号保留作测试；这三个交叉口内所有关联灯均排除在训练之外。Town05 仍只用于验证选模。

合计 **14/14 次有效闭环通过**，无碰撞、无红灯越线、无未授权或危险换道，未触发测试道路的持续限速违规和运行回退。交通灯任务的通过条件是红灯前停住并在绿灯后通过停车线，不将永久停车算作完成。每次是 22 秒、440 个物理帧的开发验证，不称为长时间全路网认证。

Town05 另有两次闭环尝试在初始化阶段遭遇 CARLA 引擎退出；第二次已改为指定已核验灯组并保留背景信号原状态，仍未完成。这两次作为基础设施中断单列，**不算模型通过，也不提供该地图的闭环性能结论**。Town05 的离线图像验证结果与此分开。停止无进展的引擎重试后，所有本轮拥有的仿真进程均已关闭。

## 运行配置与接口

已测试环境为 Linux x86、CARLA 0.9.16、Python 3.12.13、RTX 5090、PyTorch 2.11.0+cu130。新灯色模块使用已有 PyTorch、NumPy 和 OpenCV，不需要重新配置大型视觉语言模型。没有进行剪枝、量化或 J6P 板端性能验证。

最新权重位置：`/root/autodl-tmp/models/signal_lamp_state/v2/lamp_state.pt`。旧 `v1` 权重保留作对照。

最新权重 SHA-256：`d8470bf6a176037ba74e2a28f790ebb5b5ab8abe73625b37960e7f6128b4b370`。

使用 `configs/challenge_signal_generalization.json`。`traffic_signal_observer.state_checkpoint` 指向灯色权重；`static_map_path` 指向当前地图的静态停车线和灯头几何。地图文件按 OpenDRIVE SHA-256 校验，缺失灯头几何或地图不匹配时明确报错，不静默使用错误地图。

换地图后，在对应 CARLA 地图已加载的条件下导出静态几何，并在配置中填写新路径：

```bash
python lightweight_vla_adapter/scripts/export_static_traffic_controls.py \
  --port 2300 \
  --output lightweight_vla_adapter/configs/maps/Town01_traffic_heads.json
```

控制器入口仍为 `UniversalVLAController`；输入指令、同步四路图像、LiDAR、车辆状态及原意图图接口不变。前视采集为 1280×1280，VLA 四路输入仍为 224×224。新增观测不需要下游解析器重新解析原始文本。

输出仍通过 `traffic_control_contract.observation` 记录：`signal_id`、`state`、`confidence`、`timestamp_s`、`stop_distance_m`、`stop_line_source`、`detections`、`truth_state_access=false`。灯头检测项包含分类概率、当前颜色像素数、投影框和灯头索引；最终控制仍使用原 `ControlDecision` 和 PID 接口。

直接调用观测器时必须提供对应曝光帧的相机逆变换；控制器已完成这一步接入：

```python
observation = observer.observe(
    ego,
    camera_rig.front_capture(sensor_frame),
    frame=sensor_frame,
    timestamp_s=image_timestamp_s,
    camera_inverse=camera_rig.front_capture_inverse(sensor_frame),
)
```

灯色小模型模式下，缺少有效曝光位姿不会提供绿灯许可。`front_capture` 与 `front_capture_inverse` 必须使用同一个实际传感器帧号，不可混用更新的图像或车辆当前位姿。

轻量效率改动只有：把无状态 VLA 神经网络预热移到初始化阶段；复用同一决策内相同方向的风险推理；配置新灯色模型时不加载未使用的 YOLO。预热不推进指令、递归记忆或车辆状态。首次正式调用仍单独记录，不能把初始化优化解释成所有新指令均已满足时延要求。

## 脚本与证据位置

- `scripts/collect_signal_lamps.py`：多灯组采集、天气和距离变化、逐批落盘与恢复。
- `scripts/prepare_signal_lamp_labels.py`：同位姿亮灯/熄灯配对核验。
- `scripts/train_signal_lamp_state.py`：地图隔离训练、验证选模和训练外检查。
- `scripts/evaluate_signal_lamp_robustness.py`：固定权重的噪声、模糊、亮度、投影偏差及遮挡检查。
- `scripts/audit_signal_generalization.py`：不同灯组和天气的实际红停绿行测试。
- `scripts/audit_signal_extensions.py`：绿黄红绿转换、跟车、正常换道和危险换道等待的追加检查。
- `scripts/summarize_signal_generalization.py`：从原始报告汇总，不修改失败结果。
- `outputs/signal_generalization_v1/training/` 与 `training_v2/`：两次选模、预测、混淆矩阵和训练记录。
- `/root/autodl-tmp/datasets/signal_lamps_v2/`：原始裁剪、采样信息、原始及配对核验后标签。
- `outputs/signal_generalization_v2/training/`：第三轮训练、完整划分与预测结果。
- `outputs/signal_generalization_v2/robustness.json`：固定权重扰动测试。
- `/root/autodl-tmp/datasets/signal_lamps_v3/`：实际车载外参、近距离补采及静态信号组划分依据。

本实现依赖静态高精地图灯头几何和相机标定，不是无需地图的通用开放道路交通灯检测器。已覆盖的地图与天气之外，以及箭头灯、闪烁灯、严重遮挡和真实道路域，没有在本轮获得完整闭环结论。
