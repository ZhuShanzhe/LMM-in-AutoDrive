# 绿灯确认逻辑影子验证

## 已定位的问题

场景三旧的冷启动片段 `s3_navigation_projection_v103_fragment47` 中，灯色输出的短暂未知间隙反复清除已经确认的绿灯事实，车辆虽然在绿灯帧继续获得观测，但每次重新等待确认，造成低速挪动。原片段通过了已注册检查，却没有实际覆盖约 3048 米的斜接投影位置；该片段不替代后续场景三 V103 完整记录。

## 候选边界

只在同一适用信号、静态停止线关联有效、观测新鲜、此前已经连续确认绿灯且间隙不超过 0.2 秒时保留绿灯确认事实。未知帧仍按停车约束处理；恢复后至少两次不同时间戳的新鲜绿灯观测才恢复通行。重复读取同一帧不算第二次确认。红灯、黄灯、过期观测、失去停止线关联、新信号和较长间隙均重新确认，不使用未知状态作为安全证据。

候选保存在运行目录之外，没有替换场景三或场景二完整测试的冻结源码与权重。

## 已完成验证

四模块独立回归：3482 项测试及 226 项子测试通过，46.83 秒。包含未知仍停车、红黄灯不复用、过期/丢失几何不复用、长间隙不复用和重复恢复帧不计数。

候选在 186 个绿灯帧减少重复确认等待。该回放以存储的观测时间为双方时钟，没有复现真实传输新鲜度延迟；过期情形由独立回归覆盖。它不是候选驱动车辆的新闭环，不推算路线用时、交通违规率或整链路性能收益。
