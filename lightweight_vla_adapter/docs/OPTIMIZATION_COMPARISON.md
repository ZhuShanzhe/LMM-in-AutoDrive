该表不包含语言、检测、点云、几何、FSM、PID 或 CARLA，且部分算子未被计数器覆盖，因此不是整链路完整 FLOPs。若仅按三个场景的 30%／40%／30% 权重及表中配置推算，模型计数比约为 0.2867；这是配置假设下的估计，不是实际调用频率摊销结果，也不是官方实测评分。

## 实际量化结果

当前通用基础权重的投影与 FFN 已混合 INT8，视觉卷积、注意力分数与输出头保留 FP32。在 224 份保存输入、128 份开发标签上：动作准确率 67.1875%→67.1875%，风险 53.9063%→54.6875%，车道 93.7500%→93.7500%；目标速度 MAE 8.6910→8.7039 km/h。动作和车道衰减为零；输出一致率另报，不能替代标签准确率。此处仅覆盖通用神经分支，不将规则修正或递归事件头的结果混入。

原始神经风险头的绝对性能仍弱，不能将闭环执行保护解释为原始模型全部正确。INT8 改变数值位宽，不直接减少数学 FLOPs。

扩大视觉卷积量化范围的候选已完成同批 224 输入对照，128 有标签样本中动作与车道准确率不变，但风险准确率降至 43.7500%，相对衰减 18.8406%；高风险召回率降至 11.3636%，速度 MAE 增至 9.3965 km/h。该候选被排除，没有替换闭环。其 HBDK 预测时延虽降至 10.787 ms、最低内存 52.291 MB，也不能以预测效率掩盖精度不合格。新的 BEV 卷积量化候选保留原始图像编码为浮点，测试记录与被排除版本分开保存。

BEV 专用混合 INT8 候选完成相同 224 输入配对：128 标签上动作 67.1875%→67.1875%、风险 53.9063%→54.6875%、车道 93.75%→93.75%；高风险召回 54.5455%→56.8182%，速度 MAE 8.6910→8.6966 km/h。动作／风险／车道输出一致率为 100%／99.1071%／100%。BC 文件 11.575 MB，HBM 文件 28.663 MB；HBDK 估算 15.6234 ms、最低内存 71.553 MB。它相对仅投影／FFN 量化候选减少文件与最低内存，但编译器时延估算没有改善，因此不声称此项获得加速。x86 BC P95 2948.257 ms 属于功能运行时，不作为板端性能。

在同一份已校准 BC 上再优化编译调度与存储，使用 `nash-p / opt=2 / balance=2 / jobs=1`，HBDK 估算时延由 15.6234 ms 降至 9.3032 ms，下降 40.4534%；DDR 传输量由 450,730,496 降至 100,649,472 字节／次，下降 77.6697%。新 HBM 25,185,920 字节，预估最低内存 57,065,088 字节。该项不改变源 BC 和量化范围，仍属于编译器估计而非板端实测；最高单区间计算单元利用率 62.1% 不代表整链路异构利用率达到 62.1% 或 80%。

## 异构与预估

x86 实际由 GPU 执行语言、视觉与神经决策，CPU 执行传感器同步、点云／道路证据、实体关联、任务状态和控制。地平线导出按 `nash-p` 编译，支持部分进入 BPU，其他部分明确回退 CPU，不虚构 DSP 执行。

HBDK 对当前未结构精简的混合图预测 15.201 ms／次、最小内存 75.728 MB、每次 DDR 传输 443.880 MB。这些是单个模型的编译器预估，不是 J6P 实测、整链路时延或整链路内存。地平线 x86 功能仿真用于验证数值与接口；其秒级时延不能当作板端时延。当前记录不支持异构利用率达到 80%，不以算子数量占比代替利用率。
