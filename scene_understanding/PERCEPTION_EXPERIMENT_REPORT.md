# 场景感知实验报告

## 1. 指标口径

题目中的核心门槛需要分开验收：

- 文本模糊指令识别准确率不低于 95%；
- 指令解析延时不高于 50 ms；
- 决策响应全流程延时不高于 150 ms；
- CARLA 场景任务完成率不低于 90%；
- 多模态语义对齐准确率不低于 98%。

其中 90% 是无碰撞、无违规、无指令遗漏的系统级场景任务完成率，不是目标检测
recall、precision 或 mAP。本文仍以 50 ms 作为同步视觉模块的保守 P95 预算，但不会
把模拟器真值融合结果包装成视觉检测准确率。

## 2. 最终架构

默认使用双链路：

1. 同步安全链路：CARLA Actor/Map/TrafficLight API 提供闭环度量真值，YOLOP 提供
   车道线和可行驶区域，CARLA 域适配 YOLO11s 提供视觉目标候选，ByteTrack 维护轨迹，
   确定性规则计算风险并执行降级。
2. 异步语义链路：Qwen2.5-VL-3B 和 MiniCPM-V 仅保留为低频摘要对照。结果超时、
   非法或过期时直接丢弃，不阻塞控制。

视觉未检出只能表示 `unknown`，不能作为道路安全证据。距离、相对速度、TTC、信号灯
状态和变道合法性不由 VLM 或二维检测框生成。

## 3. 数据与训练

### 3.1 通用专项模型

- 训练集：50,000 张，804,695 个框；
- 验证集：5,000 张，66,974 个框；
- 来源：BDD100K 30,000 张与 nuScenes 三路前向相机 20,000 张；
- 训练/验证原图交集：0；
- YOLO11s、640、batch 48、40 轮、AMP；
- 最佳验证：Precision 69.71%、Recall 49.81%、mAP50 54.82%、
  mAP50-95 26.99%。

### 3.2 CARLA 域适配

使用修正后的 CARLA 0.9.16 灯头投影：

- `TrafficLight.get_light_boxes()` 的每个灯头独立投影，不再使用 actor 大框；
- 每个组件使用唯一 ID，并保留 `parent_world_object_id` 回连 WorldState actor；
- 行人横穿 57 帧、紧急制动 29 帧，共 86 个源帧；
- 69 个训练源帧重复增强采样 30 次，形成 2,070 个 CARLA 训练项和 12,270 个框；
- 17 个 CARLA 帧只用于域内验证；
- 同时固定抽取原训练集 12,000 张，降低灾难性遗忘；
- straight 场景 36 帧完全隔离，只用于最终测试。

域适配最佳混合验证结果为 Precision 67.86%、Recall 49.74%、mAP50 54.05%、
mAP50-95 26.43%。总体验证 mAP 未超过通用专项模型，但 CARLA 隔离集明显改善，
因此它保留为 CARLA 部署权重，不替代通用数据集研究权重。

## 4. 独立测试

BDD100K 和 nuScenes 测试清单各 1,000 帧，均排除训练验证清单；匹配协议为同类别、
IoU 0.5、一对一匹配。CARLA 使用修正投影后的 straight 36 帧、447 个可见交通灯组件。

| 权重与配置 | BDD R/P/F1 | BDD P95 | nuScenes R/P/F1 | nuScenes P95 |
|---|---:|---:|---:|---:|
| 通用专项 YOLO11s 640 | 61.16/64.96/63.00% | 27.11 ms | 57.36/45.01/50.44% | 29.09 ms |
| 通用专项 YOLO11s 768 | 63.29/65.20/64.23% | 34.18 ms | 58.79/45.23/51.13% | 38.98 ms |
| CARLA 域适配 YOLO11s 640 | 62.53/62.03/62.28% | 31.44 ms | 58.64/44.20/50.41% | 36.34 ms |
| CARLA 域适配 YOLO11s 768 | 65.10/62.57/63.81% | 25.65 ms | 59.91/44.35/50.97% | 40.66 ms |

CARLA 灯头结果：

| 权重与配置 | 召回 | 精度 | F1 | 稳态 P95 |
|---|---:|---:|---:|---:|
| 通用专项 YOLO11s 640 | 13.87% | 47.69% | 21.49% | 49.10 ms |
| 通用专项 YOLO11s 768 | 15.21% | 37.99% | 21.70% | 44.17 ms |
| 域适配 YOLO11s 640 | 17.67% | 56.43% | 26.91% | 41.36 ms |
| 域适配 YOLO11s 768 | 19.91% | 59.33% | 29.81% | 48.14 ms |
| 域适配 640 + 双分块 | 23.94% | 34.08% | 28.12% | 60.01 ms |

双分块虽然提高灯头召回，但超过 50 ms，不进入默认实时链路。阈值从 0.10 降到
0.05 或 0.025 没有得到更好的召回/精度折中，0.025 的 P95 还超过 50 ms，因此最终
阈值保持 0.10。

## 5. 场景任务完成率

当前汇总了三类 CARLA 0.9.16 场景：

| 场景 | 结果 | 完成条件 |
|---|---|---|
| 直线行驶 | 成功 | 到达目标且保持车道 |
| 行人横穿 | 成功 | 行人通过并清空冲突区 |
| 紧急制动 | 成功 | 前车急停后保持安全间距停车 |

当前结果为 3/3 完成，任务完成率 100%，碰撞率 0，违规率 0，达到 90% 门槛。
但三次运行只是工程冒烟与接口验收，不足以形成统计结论。正式报告前应增加不同路线、
天气、速度、出生点和随机种子，至少形成可重复的批量场景矩阵。

## 6. 推荐配置

CARLA 实时默认：

```bash
python -m scene_understanding.realtime_perception.run \
  --backend yolop_yolo11 \
  --yolop-root /root/autodl-tmp/models/external/YOLOP \
  --yolo11-weights /root/autodl-tmp/models/scene_understanding/yolo11s_specialized_carla_v1/weights/best.pt \
  --image-size 640 \
  --object-image-size 640 \
  --score-threshold 0.10 \
  --capture-index /path/to/capture_index.jsonl \
  --output /path/to/perception_frames.jsonl \
  --summary /path/to/perception_summary.json
```

独占 RTX 5090 且希望提高小目标召回时，可将 `--object-image-size` 改为 `768`。其
CARLA P95 为 48.14 ms，余量较小，不应与 CARLA 渲染或其他重 GPU 任务并发。
`--infrastructure-tiles` 仅用于离线分析。

## 7. 结论与边界

- 当前三场景任务完成率达到题目 90% 门槛，但样本规模尚小；
- 纯二维检测远未达到 90%，也不需要把它解释成题目中的 90%；
- 域适配在基本保持 BDD100K/nuScenes 泛化的同时，提高了 CARLA 灯头召回和精度；
- CARLA 闭环必须继续使用 Actor/Map/TrafficLight API 作为安全真值；
- 多模态语义对齐 98% 仍需在“决策相关对象”标注集上单独验收，不能用三次任务成功
  或模拟器真值自匹配替代；
- 正式达标结论需要批量场景、端到端 150 ms 测量和指令解析模块联合测试。
