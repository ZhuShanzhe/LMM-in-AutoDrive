# Perception training and rainy-night audit (2026-08-05)

## Scope

This audit checks whether the optional scene-understanding detector improves
the current CARLA rainy-night chain. Model weights and datasets remain outside
Git and are expected to be supplied with the Docker image or the submission
weight package.

## Training data and result

- Dataset: converted nuScenes mini, using relative dataset YAML paths.
- Training: YOLO11s, 10 epochs.
- Validation: precision 0.62968, recall 0.51338, mAP50 0.55095 and
  mAP50-95 0.25549.
- Per-class mAP50-95: vehicle 0.44220, pedestrian 0.27319, cyclist
  0.13029, motorcycle 0.07385 and traffic cone 0.35792.
- Experimental checkpoint package path:
  `models/scene_understanding/yolo11s_nuscenes_mini_v2/weights/best.pt`.

The Waymo authorization is valid, but Google Storage/OAuth requests from the
current host time out. The download manifest and conversion tools are ready;
this network failure is not treated as a dataset-permission failure.

## Same-capture CARLA comparison

Both checkpoints were evaluated on the same 1,434-frame Scene 3 rainy-night
capture. The metric is a front-camera category-presence proxy, not 2D or 3D
mAP.

| Checkpoint | Vehicle presence recall | Pedestrian presence recall | p95 latency |
| --- | ---: | ---: | ---: |
| CARLA-specialized v1 | 43/107 = 40.19% | 0/12 = 0% | 43.493 ms |
| nuScenes-mini v2 | 33/107 = 30.84% | 0/12 = 0% | 49.594 ms |

Both meet the 50 ms visual-inference budget at p95, but the nuScenes-only
checkpoint is worse in CARLA. It is therefore retained as an experimental
real-data checkpoint and is **not** selected for the simulation controller.

## Model deficiencies and next training action

1. Pedestrian recall is the blocking perception deficiency. The safety result
   currently relies on simulator ground truth and deterministic safety gates,
   not on the detector alone.
2. The real-to-sim domain gap causes negative transfer for vehicles. Future
   training should mix CARLA rainy-night samples with nuScenes/Waymo instead of
   fine-tuning only on real-camera data.
3. Counterfactual samples must include visually similar scenes with changed
   actor intent (crossing/not crossing, cut-in/keep lane, safe/unsafe target
   gap) and must balance emergency actions explicitly.
4. Model selection must use a joint gate: real-data mAP, CARLA rainy-night
   pedestrian/vehicle recall and latency. A checkpoint that improves only one
   domain must not replace the production checkpoint.

## Reproduction

Use `scene_understanding/scripts/train_yolo11_specialized.py` and the portable
dataset YAML generated by the conversion scripts. Keep dataset roots and
weights outside the repository and mount them at the relative package paths
documented above.
