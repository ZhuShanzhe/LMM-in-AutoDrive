## CARLA 场景与终止判定

| 场景 | 成功条件 | 失败条件 |
| --- | --- | --- |
| `straight_driving` | 自车距内部终点不超过 3 m，横向偏移不超过 1 m | 碰撞或超时 |
| `basic_voice_control_5km` | 5 km 路线完成，四条基础指令均已输出，无碰撞且无非法压线 | 碰撞、非法压线、路线规划未能满足右转/变道指令 |
| `emergency_brake` | 前车制动已触发；自车速度不超过 0.5 km/h 持续 1 s；前车间距至少 5 m | 碰撞、超时或停车间距不安全 |
| `pedestrian_crossing` | 行人完成横穿并在最小人车距离后继续远离；无碰撞 | 碰撞或超时 |

场景负责提供可复现的任务目标和客观终止判定；策略负责输出驾驶动作，不应自行声明评测成功。
