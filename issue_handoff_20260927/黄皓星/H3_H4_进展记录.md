## H4：转向落地点绑定

发现 `ScheduledSceneBridgePolicy._bind_planned_turn_target()` 已收到路线规划器的目标，但此前没有将该目标写入 TURN 步骤。因此，合法的路线计划可能在场景决策边界因缺少 `target_location` 被安全阻断。

修复原则：

1. 只接受包含有限 `x/y` 的路线目标；可选保留 `z/yaw/reference`。
2. 仅绑定下一个 TURN/U_TURN 步骤，避免把同一交叉口目标错误复用到后续转向。
3. 不覆盖上游已提供的精确 `target_location`。
4. 缺失或非法目标保持未解析，由现有决策层继续等待/拒绝；不绕过信号或安全门。

新增 `experiment/CARLA/tests/test_scheduled_turn_target_binding.py`，覆盖左右转、多个转向步骤、缺失/非法目标与上游已有目标。

验证命令：

```bat
conda run -n pytorch python -m pytest -q --basetemp "%CD%\pytest-handoff-h4-tmp" experiment\CARLA\tests\test_scheduled_turn_target_binding.py experiment\CARLA\tests\test_voice_schedule_policy.py scene_understanding\tests\test_control_decision.py
```

结果：`38 passed, 3 subtests passed`。
