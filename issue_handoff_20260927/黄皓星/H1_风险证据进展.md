# H1：风险证据与动作冲突定位进展

## 本次变更

在 `experiment/CARLA/universal_vla_controller.py` 的视觉风险与前向雷达融合边界新增了向后兼容的 `risk_evidence` 字段；不改变既有制动、减速或安全门决策。

该字段提供：

- `status`：`CONFIRMED_HAZARD`、`MODEL_ONLY` 或 `INSUFFICIENT_EVIDENCE`；
- 传感器帧、观测时间、决策时间、观测年龄与有效截止时间；
- 雷达候选数、最近障碍距离，以及视觉模型和物理雷达的融合来源。

判定原则：

1. 只有在有效期内的物理雷达目标才可标记为 `CONFIRMED_HAZARD`。
2. 高风险模型输出但没有物理确认时标记为 `MODEL_ONLY`，保留原有风险等级和动作建议。
3. 空雷达、无时间戳或陈旧雷达均标记为 `INSUFFICIENT_EVIDENCE`；它们不构成“道路安全”或“可恢复”的结论。
4. 陈旧的近距离物理回波仍保留既有制动输入，证据标签不会静默放开动作。

## 新增回归

`experiment/CARLA/tests/test_unified_architecture.py` 新增用例覆盖：

- 新鲜物理障碍返回 `CONFIRMED_HAZARD`，并生成有效截止时间；
- 过期物理观测返回 `INSUFFICIENT_EVIDENCE`，但仍不解除既有紧急制动；
- 新鲜空雷达快照不能清除高风险视觉模型结果，仍为 `MODEL_ONLY`。

建议在具备 CARLA Python 包的环境中执行：

```bat
conda run -n pytorch python -m pytest -q --basetemp "%CD%\pytest-risk-evidence-tmp" experiment\CARLA\tests\test_radar_ground_filter.py experiment\CARLA\tests\test_unified_architecture.py -k "forward_radar_evidence or physical_forward_radar_caution_and_clear_paths or physical_forward_radar_emergency_preempts_visual_miss or ground_filter_does_not_disable_physical_safety"
```

- 目标车道风险由变道/计划链路生成，尚未写入本次的前向雷达证据对象；需要与王皓然确认统一的消费字段后再接入。
- 本次不能据此声称已复现或修复仿真场景中的动作冲突；它建立的是同帧风险来源、新鲜度和有效期的可追踪基础。
