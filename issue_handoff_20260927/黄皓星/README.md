## 问题与任务

### H1 [P0] 风险证据与动作冲突定位

**证据：** 场景二有79帧、场景三有19帧：风险头为high/critical时原始动作仍为accelerate。这是两个输出的不一致，不是真值标注的危险误判率。

**修改任务：** 核对候选实体、前向/目标车道风险、物理观测、时间戳和融合来源；输出风险依据及有效期，区分可确认危险、证据不足和单一模型分数。与王皓然确认风险输入的使用位置。

**验收：** 同帧证据可追溯；空观测不等于安全；真实障碍仍触发保护；恢复只使用新鲜证据，不靠关闭风险判断实现行驶。

### H2 [P0] 行人与上下客等待的观测谓词

**证据：** 执行层仅实现PATH_CLEAR及左右车道安全谓词，PEDESTRIAN_CLEAR/PASSENGERS_CLEAR缺少对应完整的观测消费链。

**修改任务：** 提供带对象、冲突区域、时间戳、有效性和来源的清空证据；与王皓然约定确认接口。上下客完成不可从无行人或低风险推断，需消费场景/车辆事件或明确UNKNOWN。

**验收：** 遮挡、丢帧、过期、对象仍在冲突区均不得判clear；明确离开且连续观测才可确认。新增谓词正反例。

### H3 [P1] 雷达过滤与传感器就绪回归

**证据：** 场景三60秒测试首帧出现no synchronized RGB/LiDAR frame is available，随后1199条有效决策；本轮未再出现旧的持续近距雷达阻塞。已有地面过滤修复需要守住真实障碍召回。

**修改任务：** 核对初始化就绪条件、传感器帧龄、雷达地面过滤的高度/朝向/运动依据；扩展地面、坡道、矮障碍、真实前车及不同安装姿态的子单元用例。

**验收：** 首帧未就绪安全等待且可恢复；不把陈旧帧当新帧；不能按固定10.5米等距离屏蔽障碍。历史问题标为已修复回归，不写成当前必现。

### H4 [P0] 转向落地点与信号证据接口

**证据：** 合成合法TURN输入缺少target_location时被执行决策阻断；补目标后READY。场景二配置的TURN只含direction。

**修改任务：** 提供通用的路口/车道可达目标解析接口及关联信号证据，目标来自道路拓扑而非场景专用坐标；王皓然负责执行层接入。先核对在线上游是否已补目标，不能把合成探针等同于实车必现。

**验收：** 左右转、直行、连续路口、无匹配及多候选均有测试；不匹配时明确等待/拒绝；红灯约束不得绕过。
