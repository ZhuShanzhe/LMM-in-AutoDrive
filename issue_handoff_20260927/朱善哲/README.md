**证据：** 当前权重在场景二79帧、场景三19帧高风险输出中均建议accelerate，最终执行仍由约束处理；该统计仅说明输出冲突。

**修改任务：** 复核固定权重与输入契约；对接黄皓星的有效观测标记及王皓然的执行目标，比较原始输出、约束后输出和实际反馈。保存有真值支持的模型失败，不将保护层介入次数当模型准确率。

**验收：** 同源输入可复查、权重版本明确；区分模型错误、传感器错误和接口错误；需要模型改动的结论须有排除接口因素的证据。

**证据：** 所有问题包来自同一代码快照；感知谓词、TURN目标和速度目标存在跨模块依赖。

**修改任务：** 协调H2/H4到W2的字段契约、L1文本来源标记以及X1/X2评测口径；审查各自子单元结果后合并，交刘旭做闭环复测。

**验收：** 不覆盖其他人的修改；接口有正反例；离线通过与闭环通过分开报告；维持安全底线。
