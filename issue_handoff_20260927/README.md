## 证据口径

- 场景一40秒、场景二90秒、场景三60秒是诊断窗口，均退出3（INCOMPLETE_EVIDENCE），不是全程通过。
- 场景二90秒：1800条有效决策、361.347米、最高观测速度42.688km/h、0/15命令完成，SET_SPEED占1777帧。
- 场景三60秒：1199条有效决策、首帧1次同步输入未就绪，末条路线进度346.546米。旧的持续近距雷达阻塞本轮未复现。
- 场景二79帧和场景三19帧出现高风险头与原始accelerate冲突；这不是独立危险真值准确率。最终执行与原始模型输出分开保存。
- 额外20秒场景二采集有400条决策及真实多视角RGB/LiDAR/雷达。包内只选连续8帧作输入契约调试，另附峰值状态摘录；不将它与90秒风险冲突帧混用。录制有I/O开销，不作性能基准。
- 合成探针均明确标注：TURN缺少目标、低风险WAIT和RETURN_WHEN_SAFE适配。它们用于接口验证，不充当真实场景准确率样本。
- 车道证明耗尽既可能涉及任务未及时完成也涉及夹具边界，待X2区分；不得直接把所有SCENE_INVALID都改成通过。
- 测试日志里的占位0延时不是测得零耗时。以有效计时字段和明确统计范围为准。

## 证据文件

`_common/scene*/decision_excerpt.json.gz`保留原日志行号与完整选中记录；`decision_summary.json`来自整份日志统计。`provenance.json`含原文件SHA256和来源，原始完整日志留在服务器。`evaluation_only_truth_excerpt.json`仅用于核验，不允许作为模型在线输入。

`_common/capture_subset.zip`含连续8帧原始字节及实际选择的传感器帧、外参、输入上下文、记录输出和校验清单；不保证截断时序回放逐位重现在线模型隐藏状态。`_common/previews`为其中真实前视图。未采集到的故障时刻图片没有补造。
